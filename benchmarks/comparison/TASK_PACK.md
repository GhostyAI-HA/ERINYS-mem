# TASK PACK: Baseline Comparison Harness (w1)

## Goal
Build `benchmarks/comparison/` so that reviewers can see ERINYS vs trivial baselines under identical conditions. This fills the "no same-condition baseline" gap for an ARR submission (deadline 2026-10-12).

## Deliverables (all inside `benchmarks/comparison/`)
1. `common.py` — shared benchmark adapters that REUSE the ingestion + evaluation logic of the existing scripts (`../locomo_bench.py`, `../convomem_bench.py`). Import from them; do NOT copy-paste eval logic (single source of truth for scoring). If import requires small refactors of those files, do NOT modify them — instead wrap via importlib and thin adapters.
2. `baseline_rag.py` — Naive RAG baseline: session-level chunks, `BAAI/bge-small-en-v1.5` embeddings via the same `embedding_engine` used by existing benches (import it), cosine top-k. No FTS, no boosting, no RRF.
3. `baseline_bm25.py` — Lexical baseline: Okapi BM25. Vendor a minimal, documented BM25 implementation in `bm25_impl.py` (~60 lines, k1=1.5, b=0.75, cite formula in docstring). No new pip dependencies. (Do NOT use FTS5 for this one — FTS5-only is reserved as an ERINYS ablation, this baseline must be pure lexical BM25.)
4. `run_comparison.py` — CLI: `--bench {locomo,convomem} --system {rag,bm25} --limit N --top-k K`. Defaults: full datasets, top_k=10 (matching BENCHMARKS.md config). Writes per-run JSONL + summary JSON into `results/` (same naming style as existing benches: `summary_{system}_{bench}_{timestamp}.json`) AND appends one row to `results/comparison.csv` with schema:
   `system,benchmark,mode,n,r_at_k,perfect_pct,latency_p50_ms,latency_p95_ms,ingest_wall_s,retrieval_llm_calls`
   (`retrieval_llm_calls` is always 0 for these systems — the column exists for the paper table.)
5. `make_table.py` — reads `results/comparison.csv` (+ the existing ERINYS summary JSONs in `../results/`) and emits a Markdown table AND a LaTeX `tabular` to stdout. Numbers in the paper will be generated by this script ONLY (no hand-typed numbers).
6. `README.md` — fairness contract: identical inputs (same adapter), identical embedding model where applicable, identical scoring (reused eval code), pinned env (`pip freeze` dump instructions), and any ingestion-granularity differences documented.
7. Smoke tests: `--limit 5` must complete in <2 min per system per bench.

## Metric definitions (must match existing benches exactly)
- Primary: R@k as computed by the existing eval code (evidence recall, partial credit) — reuse it.
- Also record perfect_pct and zero_pct where the existing code provides them.
- Latency: wall-clock per retrieval call, report p50/p95 in ms.
